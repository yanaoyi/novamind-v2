**遗留动作（需要 BOSS 决定）**：口令已经在公开仓库的历史里出现过，严格做法是轮换本机数据库口令
（`ALTER USER novamind PASSWORD '新口令';` 并同步 `backend/.env`）。这属于会打断当前运行环境的动作，等 BOSS 一句话再动。

## 本轮额外发现并修掉的真缺陷（不在 muse 报告里）

**正文类提示词被强制结构化输出**（`service/model_invoker.go`）

* 现象：真实模型端到端验收在「AI 写本章」步骤随机失败，任务报「模型没有返回正文」，重试 3 次全空；换一组上下文又能成功，看起来像玄学。
* 根因：`RunPrompt` 对所有模板一律 `JSONMode=true` + 系统提示「只输出要求的 JSON」，而「写本章 / 续写改写 / AI 问答」要的是**小说正文**。上游在 `response_format=json_object` 下遇到"要正文"的提示会直接返回**空内容**（HTTP 200 + `content: ""`），于是被当成"模型没返回正文"。
* 修复：拆出 `RunTextPrompt`（不传 `response_format`、系统提示改为"直接输出正文/回复"），写本章、编辑器改写、AI 问答改走文本模式；分析类（人物/世界/剧情/摘要/一致性/就地分析）保持结构化输出（§57 不变）。
* 验证：修复后真实模型端到端 **37/37 全过**（含新补的「采纳 AI 大纲 → 落成章节」环节）；新增单测锁住两套系统提示不能混（`service/model_invoker_test.go`）。
